<img width="1540" height="1430" alt="image" src="https://github.com/user-attachments/assets/1c4e2c88-6ee2-4683-b0e9-e36a24c150f8" />## Setup
1. Install DDEV environment following blow link https://ddev.com/get-started/ (use other lamp environment if you have).
2. Run ```ddev start``` under project directory.
3. Run ```ddev composer install``` under project directory
4. Run ```ddev drush si --existing-config``` command after ddev start(use ```drush si --existing-config``` in your server if you use other lamp environment).
5. Run ```ddev drush dcdi```
